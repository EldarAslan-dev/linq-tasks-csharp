# C# LINQ Tasks & Practice Exercises

Bu repozitoriya C# dilində **LINQ (Language Integrated Query)** mövzusuna aid müxtəlif səviyyəli tapşırıqların həllərini əhatə edir.

## 📌 Məzmun və Tapşırıqlar

### 1. Basic Filtering and Selection (Əsas Filtrləmə və Seçim)
- **Even numbers:** `numbers` siyahısından cüt ədədlərin filtrlənməsi.
- **Cities starting with L or T:** "L" və ya "T" hərfi ilə başlayan şəhərlərin tapılması.
- **High salary employees:** Maaşı $70,000-dən çox olan işçilərin seçilməsi.
- **Young employees:** Yaşı 30-dan az olan işçilərin tapılması.

### 2. Projection and Transformation (Proyeksiya və Çevrilmə)
- **Square numbers:** Ədədlərin kvadratından ibarət yeni siyahının yaradılması.
- **City lengths:** Şəhər adlarının uzunluğu (boşluqlar nəzərə alınmadan) ilə birlikdə çıxarılması.
- **Employee names:** Yalnız işçilərin adlarının çıxarılması.
- **Employee summary:** Ad, Şöbə və maaşın ortalamadan yuxarı olmasını göstərən anonim obyekti (`Anonymous Type`) yaradılması.

### 3. Sorting (Çeşidləmə)
- **Sort cities:** Şəhər adlarının əlifba sırası ilə düzülməsi.
- **Sort employees by salary:** İşçilərin maaşa görə azalan sıra ilə sıralanması.
- **Multi-level sorting:** Əvvəlcə şöbəyə, sonra yaşa görə çoxsəviyyəli çeşidləmə.
- **Reverse numbers:** Ədədlərin böyükdən kiçiyə düzülməsi.

### 4. Grouping & Aggregation (Qruplaşdırma və Statistik Əməliyyatlar)
- **Group employees by department:** Şöbələrə görə qruplaşdırma və işçi sayının tapılması.
- **Group orders by customer:** Müştərilərə görə sifarişlərin qruplaşdırılması və ümumi cəm.
- **Group numbers by even/odd:** Ədədlərin cüt və tək kateqoriyalarına ayrılması.
- **Average salary:** Bütün işçilərin ortalama maaşının hesablanması.
- **Department statistics:** Hər şöbə üzrə ortalama maaş və işçi sayı.
- **Sum, Count & Min/Max:** Cəm, şərtli say və ən gənc/ən yaşlı işçilərin tapılması.
